# Luxora (static build)

AI shopping assistant prototype. Products, brands and prices are real (Oura, Samsung, Garmin, Apple, Sony), read from the retailers' own pages on Nov 3, 2026 (America/Chicago); they can change, so confirm at the retailer. Luxora sells nothing: each product has a "Buy at <retailer>" link. The in-app cart/checkout is a demo that takes no payment. Product pictures are illustrative images, not official photos.
This is the static build of Luxora: the chat runs fully in the browser (`js/offline.js`), no backend needed.
